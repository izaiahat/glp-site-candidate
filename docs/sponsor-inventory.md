# Sponsor factual inventory (PR20 readiness successor)

`data/sponsor-inventory.json` is the maintained registered-build input. Its shipped state is **empty** (`selection: null`, `orders: []`); normal builds emit no sponsor routes or directory advertisement. `GLP327_SPONSOR_PLACEMENT_PREVIEW=1` emits only the existing neutral examples with disabled actions. Do not populate inventory from the test fixture.

After genuine payment custody and exact creative/release approval, the site owner can review a source change selecting **one** `order_reference` and slot `providers-directory-panel`. The selection must resolve to exactly one order whose `inventory_slot` matches. The registered build feeds the same order to `/providers/` and `/sponsors/<slug>/`; organic results are unchanged. Reserved `rates` and `example-provider` slugs cannot be live creative.

Each order carries provider identity, safe HTTPS destination, explicit affiliate status, existing operator/partner/eligibility/inventory approvals, `release_approved: true`, reviewed `order_reference`, `held: false`, `us_provider: true`, and `starts_at`/`ends_at` defining the active 720-hour term. These fields are **not payment proof**. `paymentVerified` still fails closed for all callers; the separate PayPal owner must supply authenticated business-producer custody and the reviewed site handoff. No credentials or payment code are changed here.

The `facts` object requires `program_summary`, `published_price`, `eligibility_states`, and `current_offer`. Each contains nonempty bounded `text`, a safe `source_url`, and a valid, nonfuture ISO `checked_at` date. Price text must include the reviewed basis/exclusions; offer text must explicitly state the reviewed offer or its absence. These are reviewed reported facts, never evidence of clinical outcomes or licensing. Renderers escape text, show source/check date and keep Sponsored/payer/affiliate disclosures next to the action. Sponsor pages remain noindex, outside navigation/sitemap. Final creative/legal/privacy/design/release acceptance is separate.

The unmocked payment verifier rejects the fixture. No production override/verifier injection exists. `GLP327_FIXTURE_HTML_OUT` optionally writes local test HTML outside `public/` for localhost capture; it is not a build/release switch.

Outward `placement-template.pdf` now contains one native unscrolled directory viewport per responsive size (two pages total). The internal exact review archive keeps complete directory evidence unchanged. Bounded PDF inspection is not independent Fable acceptance or installation parity.
